# U6 Pro reference captures

What a real UniFi U6 Pro (firmware 8.8.14) and UniFi Network 11.1.50 did,
captured to model the agent on: the inform payload (`mca-dump*.json`),
the system_cfg and hostapd configs the controller wrote (`config-apply/`),
and the three study write-ups (`study-*.md`).

Addresses, names, SSIDs, serials and keys are replaced or redacted. The
firmware's own files (init and hotplug scripts, the config scripts) and the
`strings` dumps of Ubiquiti's programs, which the studies quote, are
Ubiquiti's and are not in this repository; the studies keep the quotes they
rely on.
